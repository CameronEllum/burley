# Plotly Charts

Burley renders `plotly` fenced blocks with the bundled Plotly bundle. Each
block is either an inline JSON spec or a `src:` directive that points at a
JSON file next to the note. Move the cursor into a block to edit the raw spec;
move it away and the chart comes back.

## Line chart

```plotly
{
  "data": [
    {
      "type": "scatter",
      "mode": "lines+markers",
      "name": "First paint",
      "x": ["Jan", "Feb", "Mar", "Apr", "May", "Jun"],
      "y": [182, 164, 151, 142, 128, 119],
      "line": { "width": 2 }
    },
    {
      "type": "scatter",
      "mode": "lines+markers",
      "name": "Fully loaded",
      "x": ["Jan", "Feb", "Mar", "Apr", "May", "Jun"],
      "y": [640, 598, 552, 501, 470, 433],
      "line": { "width": 2, "dash": "dot" }
    }
  ],
  "layout": {
    "title": { "text": "Median load time" },
    "xaxis": { "title": { "text": "Month" } },
    "yaxis": { "title": { "text": "Milliseconds" } },
    "legend": { "orientation": "h", "y": -0.25 }
  }
}
```

## Grouped bar chart

```plotly
{
  "data": [
    {
      "type": "bar",
      "name": "LF",
      "x": ["Notes", "Docs", "Specs"],
      "y": [412, 1098, 3]
    },
    {
      "type": "bar",
      "name": "CRLF",
      "x": ["Notes", "Docs", "Specs"],
      "y": [18, 64, 1]
    }
  ],
  "layout": {
    "title": { "text": "Files in the vault" },
    "barmode": "group",
    "yaxis": { "title": { "text": "Files" } }
  }
}
```

## Bubble scatter

Color and size can both come from data; the default colorway leaves the
colorbar alone.

```plotly
{
  "data": [
    {
      "type": "scatter",
      "mode": "markers",
      "x": [12, 38, 21, 64, 47, 9, 55, 30],
      "y": [3.1, 6.8, 4.2, 8.9, 7.1, 2.4, 8.2, 5.3],
      "text": [
        "Alpha", "Bravo", "Charlie", "Delta",
        "Echo", "Foxtrot", "Golf", "Hotel"
      ],
      "marker": {
        "size": [14, 24, 18, 34, 26, 10, 30, 20],
        "color": [2, 7, 4, 9, 6, 1, 8, 5],
        "colorscale": "Viridis",
        "showscale": true,
        "colorbar": { "title": { "text": "Score" } }
      }
    }
  ],
  "layout": {
    "title": { "text": "Score vs. effort" },
    "xaxis": { "title": { "text": "Effort (hours)" } },
    "yaxis": { "title": { "text": "Score" } }
  }
}
```

```plotly
{

    {
      "type": "heatmap",
      "x": ["W1", "W2", "W3", "W4", "W5", "W6"],
      "y": ["Mon", "Tue", "Wed", "Thu", "Fri"],

        [7, 12, 20, 16, 10, 14],

  "layout": {

```

## Spec loaded from a file

The block below only contains a relative path. Burley fetches
`data/response-times.json` through the asset endpoint, so the data stays out
of the note and can be regenerated by a script.

```plotly
src: ./data/response-times.json
```
